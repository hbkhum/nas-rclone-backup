Privacy policy

Last updated: 2026-11-07

nas-rclone-backup is a private tool used only by its owner, on the owner's own Google account.

What it accesses

It uses the Google Drive API to create, update and delete the backup files it writes into the owner's Google Drive.

What it stores and shares

The OAuth token is stored only on the owner's NAS and in the owner's secrets server. No Google user data is sold, shared with third parties, used for advertising, or used to train any model. No data is sent anywhere except the owner's own Google Drive.

Revoking access

Access can be revoked at any time from Google Account › Third-party connections.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
